# Bağımlılıklar

## Gerekli
- Windows 10/11 x64
- Visual Studio 2022, Desktop development with C++
- MSVC toolset ve Windows SDK
- CMake
- Resmi CEF Windows x64 standard binary distribution

## İsteğe bağlı
- Inno Setup 6 (installer oluşturmak için)
- 7-Zip (arşiv işlemleri için; PowerShell `Compress-Archive` alternatifi var)

CEF proje sitesi: https://cef-builds.spotifycdn.com/
CEF API dokümantasyonu: https://cef-builds.spotifycdn.com/docs/
