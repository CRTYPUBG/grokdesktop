# Güvenlik İlkeleri

- TLS doğrulamasını kapatma.
- CEF sandbox'ını düşünmeden devre dışı bırakma; resmi dağıtımın yönergelerine uy.
- Parola, cookie, access token veya sayfa içeriği loglama.
- Profil yalnızca yerel kullanıcıya ait uygulama verileri altında tutulmalı.
- Kişisel profil, cache ve çerezler dağıtıma dahil edilmemeli.
- Grok'un login/CAPTCHA/anti-abuse kontrolleri atlatılmamalı.
- Uygulama ayrıcalıklı olarak çalıştırılmamalı.
- CEF/Chromium lisans ve bildirimleri dağıtımda korunmalı.
- Güvenilmeyen sayfa içeriğinden keyfi yerel komut çalıştırılmamalı.
